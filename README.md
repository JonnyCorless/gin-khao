# Gin Khao (กินข้าว)

Thai for daily life in Chiang Mai: an Android app whose lessons update with a git push.

- `content/`: lessons as YAML. Push and the **Publish content** workflow makes the audio and publishes the feed.
- `app/`: the app (Preact + Capacitor). Tag `v*` and **Release APK** builds a signed APK for Obtainium.
- `PLAN.md`: the full plan.

Content feed: https://jonnycorless.github.io/gin-khao/
